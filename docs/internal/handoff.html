Sažetak za developera ili AI agenta koji nastavlja rad u c:\projects\healthcare\website.

Počni ovdje

  1. Repo: rotary-healthcare-professionals/website; produkcijska grana main.
  2. Pročitaj docs/project-overview.html i docs/deployment-guide.html.
  3. Pokreni npm install, zatim npm run build.
  4. Cutover je gotov — domena je uživo. Ne diraj DNS bez potrebe; email MX zapis mora ostati (Bluehost).

Ciljna arhitektura

Pages CMS → GitHub → GitHub Actions → GitHub Pages.

  • Astro + Markdoc ostaju; projekt je čisti statički build.
  • Keystatic, React runtime i serverski adapter uklonjeni su.
  • CMS konfiguracija: .pages.yml.
  • Deploy workflow: .github/workflows/deploy-pages.yml.
  • Workflow je aktivan; ENABLE_GITHUB_PAGES=true.
  • Build ide na custom domenu: PAGES_SITE_URL=https://rotaryhealthprofessionals.org, a PAGES_BASE_PATH se ne postavlja (prazno = korijen domene).

Što još zahtijeva vanjski pristup

  1. Team plan → privatni repo: čeka ručnu primjenu odobrenog besplatnog Team plana od GitHuba (do tjedan dana). Prebacivanje repoa u privatni tek kad org plan postane team — inače se ugasi GitHub Pages.
  2. Test urednika: Karla i Drago prijava vlastitim GitHub računima + probni unos/uređivanje/brisanje vijesti.
  3. Kontakt forma: jednokratna aktivacija FormSubmit forme na /contact.
  4. Pristupi: Karla kao Owner/admin organizacije.
  5. Email pa Bluehost: preseliti email, pa tek onda ugasiti Bluehost hosting.

Trenutačna produkcija i rollback

Domena je uživo na GitHub Pagesu s uključenim HTTPS-om. Website rollback = revert commita na main (automatski se objavi ispravna verzija).
Email je i dalje na Bluehostu (MX mail.rotaryhealthprofessionals.org). Ne uklanjati Bluehost i ne dirati mail DNS zapise dok se email ne preseli. Krajnji DNS rollback (referenca): vraćanje apex A zapisa na 50.87.253.47.

Ownership pravilo

Repo, GitHub App, domena i DNS moraju pripadati organizaciji. Ne ostavljati produkciju ovisnu o osobnom računu developera. Roko je trenutačno Owner; Karlu još treba dodati kao Owner/admin. Karla i Drago ulaze u Pages CMS svojim GitHub računima; pristup ograničiti samo na potrebne korisnike i repo website.
